# Original paper resource provenance

2026-11-12. Files paper-warm.png and paper-dark.png are generated entirely by generate-paper.py using a fixed random seed, noise and short procedural strokes. No external image pixels, fonts, Paper-co files, downloaded texture samples or model outputs are included.

The original code and generated tiles in this directory are dedicated to the public domain under CC0 1.0 Universal (https://creativecommons.org/publicdomain/zero/1.0/). No attribution is required. This dedication applies only to the original resources in this directory, not to third-party reference sites or their screenshots.

Paper-co was visual reference only. Its license (https://free-paper-texture.com/license/, checked 2026-11-12) prohibits redistribution of original and modified material. None is bundled here.

Implementation: PNG tiles already include their base colors and low contrast micro detail. Tile at 512px natural resolution at 1x; avoid enlarging the grain. White theme uses no texture. PDF texture is outside original PDF pages only.
